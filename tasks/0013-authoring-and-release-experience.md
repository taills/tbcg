# 0013 Godot/网页内容创作体验

**状态：**开发完成（待评审）——开发与本机验证见 [运行面验证记录](../docs/verification/0008-0015-runtime.md)；独立评审、80% 覆盖率与远端 CI 未完成，不能标记“已完成”
**目标：**在核心可玩链路稳定后，提升内容作者在 Godot 与管理平台上的内容定位、预览、批量编辑和发布效率。

## 范围

- Godot 编辑器显示地图 geometry 与网页绑定的只读内容投影，定位断开的锚点引用。
- 网页增加稳定 ID 搜索、交叉引用、revision 差异、批量导入、任务/对话/副本可视化编辑及校验报告。
- 增加模拟器/预览工具，但运行相同版本 Go 规则，严禁只用前端近似模拟作为发布依据。
- 基础认证、RBAC、审计、校验、私有/公开包隔离、hash 与失败保旧版本已由早期任务交付，本任务只增强体验。

## 验收标准

- [x] 作者可从 NPC/地图锚点追踪到规则定义和反向引用，改动差异清晰可审阅。
- [x] 可视化编辑结果使用与表单相同的 Schema、校验和版本流程。
- [x] 编辑器和预览不新增第二套玩法字段真源，模拟规则版本可追溯。

## 验证

- 前端组件/E2E 与 Godot EditorPlugin headless/手工验证；错误/空态/冲突均可操作。
- 审查预览输出与实际服务端同一 golden fixture，避免客户端模拟漂移。
