# 0015 后续游戏领域模块纵向扩展

**状态：**未开始
**目标：**在双人副本 MVP 稳定后，逐一交付宠物/伙伴、制作、社交、交易、公会与活动，不以建表或 Schema 取代功能。

## 范围

- 每次只选一个用户可见领域，并为其 Definition/Instance、权限、事务、编辑器、API、表现和回滚建立独立子任务。
- 宠物、坐骑、制作、商店、好友、公会、跨玩家交易、活动按 PLAN 中的支持矩阵逐步推进。
- 涉及资产转移/多人并发的功能先设计数据库事务与状态 owner，再开发 UI。
- 不默认实现跨服、拍卖和复杂实时活动；需要独立产品/容量设计时另开计划。

## 验收标准

- [ ] 每个领域有可执行故事和接受标准，且是创作→校验→发布→运行→故障恢复的纵向完整 Module。
- [ ] 资产变更同 PostgreSQL 账本/幂等结果/outbox 事务，权限与所有者约束通过测试。
- [ ] 只有实际交付、测试、评审并提交后，才更新支持矩阵为 supported。

## 验证

- 每个领域单独任务文件、TDD、数据库集成与必要 E2E；扩展任务不允许多个高风险经济功能打包一次提交。
- 执行性能与安全审查，并核对对既有实例和 Release 的向后兼容。
