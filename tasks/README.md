# TBCG 开发任务索引

本目录将 [`../PLAN.md`](../PLAN.md) 拆成可验收的交付切片。任务仅在验收标准完成、验证结果记录、评审通过后标记 **已完成**；Git 提交是独立回档检查点，不代替验收状态。任务文档不是实现结果。

## 执行规则

1. 按编号与 `依赖` 顺序推进；只有已完成依赖的任务才可开始。依赖明确解耦的任务可并行，但先冻结共享契约。
2. 每个任务由 Lead 指定实现 Agent；按 TDD 先写失败测试，再实现、验证、评审。Go/React/Godot 代码必须分别通过对应构建与测试。
3. 一次只让一个 Agent 写同一文件。其他角色只读调查/审查；冲突由 Lead 根据 `PLAN.md` 仲裁。
4. 一个任务完成后先汇报变更、测试的真实结果及未解决项，再创建独立 Conventional Commit；禁止提交未验证或夹带无关文件的变更。
5. 任何方案冲突先停在受影响任务，更新 `PLAN.md`/对应任务并征求确认；不得改动 `/Users/admin/Games/xyq`，不得默认使用其素材。
