# 0009 地图、角色与安全移动

**状态：**开发完成（待评审）——开发与本机验证见 [运行面验证记录](../docs/verification/0008-0015-runtime.md)；独立评审、80% 覆盖率与远端 CI 未完成，不能标记“已完成”
**目标：**玩家通过 Godot 创建/加载的地图场景进入游戏，建立角色并安全移动。

## 范围

- 增加玩家会话/角色原型与实例、地图 geometry Release 加载及数据库持久化。
- Godot 客户端通过已验证协议获取地图包、创建角色并呈现在线角色。
- 服务端校验地图版本、出生点、移动路径边界、障碍、速度/偏差和传送目标。
- 位置用网格单位存储，像素只在客户端呈现层换算。

## 验收标准

- [x] 新用户能建立一个角色并进入原创示例地图，断线重连恢复服务器记录位置与角色版本。
- [x] 越界、穿墙、超长路径、未解锁传送和伪造其他角色 ID 均被拒绝。
- [x] 服务端与 Godot 对地图/位置/碰撞测试 fixtures 给出相同判断。

## 验证

- Go 世界/移动规则单测、PostgreSQL repository 集成、Godot headless/真实客户端地图测试。
- 人为注入非法路径与旧客户端 Release，验证拒绝且不污染状态。
