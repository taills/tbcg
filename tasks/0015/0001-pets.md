# 0015.1 宠物

**状态：**未开始
**依赖：**0012、0013（必须先确认双人副本 MVP 与创作/发布体验成熟）
**目标：**交付最低可玩的宠物获得、养成、出战和表现闭环，并抽出仅服务宠物/伙伴/坐骑的最小 common owner seam。

## 最低可玩范围

- 网页定义并发布宠物种族、成长、技能槽、获得来源和外观绑定；发布校验引用、Release 能力和回滚影响。
- Go 维护 Pet owner/Character 归属、获得、升级、出战、改名和战斗单位投影；资产变化通过 PostgreSQL 事务、幂等结果、账本/outbox 提交。
- Godot 展示宠物列表、跟随或出战状态、基础技能表现和错误反馈。

## 不做范围

- 不实现复杂繁殖、拍卖、跨服宠物市场或自动脚本训练。
- 不把宠物、伙伴、坐骑合并成一个无领域约束的通用 CRUD；common owner seam 只抽最小归属/状态版本能力。

## 验收标准

- [ ] 玩家可通过一个已发布来源获得宠物、设为出战并在战斗中看到权威投影。
- [ ] 权属、重复领取、状态版本冲突和事务未知结果不会产生重复宠物或错误出战状态。
- [ ] 网页定义/发布、Go 权威事务/owner、Godot 表现、真实 PostgreSQL、三端测试、覆盖率 80%+ 和评审均完成后才可标记 supported。
