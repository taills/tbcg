## 范围

- 定义 NPC 锚点到内容 ID 的绑定、对话选项动作、任务定义/状态、区域或交付目标、指定遭遇目标、奖励与物品实例。
- 服务端校验地图、距离、可见性、权限、任务前置、目标参与归属和重复领取；定义个人/队伍进度语义。
- 以 OptionChosen → AcceptQuest → 可信目标事件 → ClaimReward 推进任务；持久化状态、物品/货币账本、幂等结果与 outbox 同一 PostgreSQL 事务。
- Godot 负责交互展示，不本地推进任务或发奖。

## 验收标准

- [ ] 0010.1 完成后，玩家可在指定 NPC 选项中接取任务，并通过区域进入或物品交付领取一次有效奖励。
- [ ] 0011 完成后，0010.2 接入真实指定遭遇胜利事件；不匹配目标、未接取任务、非参与者、重复领取和伪造 NPC 距离均不能推进/发奖。
- [ ] 任务奖励事务失败不发成功消息；成功后断线/重试只产生一份有效货币/物品，且 outbox 可幂等重投。

## 验证

- Go 任务/背包/经济边界单测，真实 PostgreSQL 故障测试和跨端 Godot + API E2E。
- Playwright 创建/发布任务与 NPC，游戏内两客户端验证接取、交付、指定遭遇胜利和归属。
- 父任务验收以 0010.1、0010.2 的测试记录和评审结论为准；仅完成业务 Schema 或表结构不算完成。
