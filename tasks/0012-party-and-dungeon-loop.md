# 0012 组队与副本完整闭环

**状态：**未开始
**目标：**组队成员共同进入版本固定的多阶段副本、战斗并安全领取一次奖励。

## 范围

- 实现队伍创建/邀请/加入/离队与成员命令权限、地图/副本准入和玩家掉线状态。
- 定义 Dungeon Instance 的参与人、阶段图、遭遇、限次及不可变 Release 闭包。
- 阶段转换、超时/投降/队伍解散、战斗结果与副本奖励采用可恢复状态机。
- 战斗结束不直接改他人背包；每位合格参与者通过幂等结算入口提交一次奖励。

## 验收标准

- [ ] 至少双客户端可组队，依副本准入规则共同完成两个阶段的遭遇与结算。
- [ ] 断线重连恢复副本阶段，非队员/已退出成员不能冒领队伍奖励。
- [ ] 副本持续引用开始时 Release；崩溃/重复提交不重复掉落，失败能恢复或明确失败状态。

## 验证

- Go 状态机、并发、权限、超时测试和真实 PostgreSQL 故障集成测试。
- Godot 双客户端 E2E；测试进行中发布新版本时，旧副本不发生混版。
